교안·퀴즈·문체 변환 등 텍스트 생성에 사용

높을수록 품질이 좋아지고 시간과 비용이 늘어납니다. Gemini는 '높음'이 상한입니다.

교안 내 삽입 이미지 생성에 사용 (16:9). Nano Banana 모델은 장마다 요금이 붙고 무료 키로는 못 쓸 수 있습니다. SVG 삽화는 글 모델이 그려 무료 키로도 됩니다. Higgsfield 모델은 아래 Higgsfield 설정을 쓰고 크레딧이 듭니다. Gemini 키가 없으면 글 모델이 SVG 삽화를 그립니다.

탭을 만들 때 넣을 이미지 수입니다. 이미지 한 장에 수십 초가 걸리므로 줄이면 생성이 빨리 끝납니다. 남긴 자리는 '일괄 이미지 찾기'로 나중에 채울 수 있습니다.

키 미등록

위 이미지 생성 모델에서 Higgsfield를 고르면 사용합니다. Higgsfield는 브라우저에서 직접 부를 수 없어 처음 한 번 Cloudflare Worker 중계를 배포해야 합니다: → Cloudflare 대시보드 Workers & Pages → Create → Worker → Edit code에 붙여 넣고 Deploy → 나온 주소를 위 칸에 넣고 연결 확인. 비용은 Higgsfield API 잔액에서 나갑니다.

• API Key와 모델 설정은 브라우저 로컬에만 저장됩니다.
